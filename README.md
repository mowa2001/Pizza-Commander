# Pizza Commander

Pizza Commander est un site web simple pour commander des pizzas.  
Ce projet a été réalisé dans le cadre d’une formation.  

## Description

- Page d’accueil avec présentation et lien vers le menu.  
- Menu des pizzas disponible (page statique).  

## Technologie

- HTML/CSS simple  
- Version statique générée à partir d’un projet Django
  
## Instructions pour lancer localement

1. Télécharger ou cloner le dépôt.  
2. Ouvrir `index.html` dans un navigateur web.  
3. Naviguer entre les pages statiques `index.html` et `menu.html`.
